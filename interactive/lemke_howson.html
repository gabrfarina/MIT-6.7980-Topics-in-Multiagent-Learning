Lemke–Howson, pivot by pivot

Drop one label from the artificial equilibrium and follow the unique path of almost completely labeled vertices until the missing label returns. Every vertex, label and tableau below is computed exactly with rational arithmetic.

    Bimatrix version: P = {x ≥ 0 : CTx ≤ 1} and Q = {y ≥ 0 : Ry ≤ 1}, for the game (R, C). Labels 1…m are the row player's strategies, m+1…m+n the column player's. A vertex x has label i when xi = 0 and label m+j when column j is a best response to x; symmetrically for y.

    Symmetric version, as in the notes: the polytope Rz ≤ 1, z ≥ 0. Action i is represented when zi = 0 or eiTRz = 1; a democracy represents every action. Running it on the symmetrized game [[0, R], [CT, 0]] reproduces the bimatrix path pivot for pivot.

    When a matrix has negative entries or would give an unbounded polytope, a constant is added to it; this does not change any equilibrium. Payoffs that already give bounded polytopes are used as is, so the numbers match the tables in the notes. Ties are broken with the lexicographic minimum-ratio rule, so degenerate games such as rock–paper–scissors work too. The simplex view is the projection x ↦ x/‖x‖1; the vertex 0 sits outside the simplex.

    References: C. E. Lemke and J. T. Howson, Jr., “Equilibrium points of bimatrix games,” Journal of the SIAM 12(2), 1964. B. von Stengel, “Computing equilibria for two-person games,” Handbook of Game Theory, vol. 3, 2002.
